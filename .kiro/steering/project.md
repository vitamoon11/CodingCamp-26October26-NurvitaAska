# Project Steering — Expense & Budget Visualizer

Build a mobile-friendly expense tracking web app using only:
- HTML for structure
- CSS for styling
- Vanilla JavaScript (no frameworks)
- Browser Local Storage for client-side data persistence
- No backend server

Required features:
1. Transaction form with Item Name, Amount, and Category (Food, Transport, Fun).
2. Validate that all fields are completed and amount is a positive number.
3. Transaction list showing name, amount, and category, with delete action.
4. Total spending summary that updates when transactions are added or deleted.
5. Pie/doughnut chart showing spending distribution by category and updating with data changes.

Technical constraints:
- Keep exactly one CSS file inside css/ and one JavaScript file inside js/.
- Support modern Chrome, Firefox, Edge, and Safari.
- Keep the interface clean, readable, responsive, and easy to use.
- No test setup required.
- Keep code readable and avoid unnecessary dependencies.
- The project must be publishable through GitHub Pages.

Optional challenges from the assignment (choose three):
- Custom categories
- Monthly summary view
- Sort transactions by amount or category
- Highlight spending over a set limit
- Dark/light mode toggle

When making changes, preserve the constraints and clearly explain which optional challenges are implemented.
